# 實機驗收（Phase 10）

本文件分開記錄「已用什麼方式驗證」與「尚未驗證」。**沒有在真實手機上測過的項目，一律標示為未驗證**，不以模擬器結果代替。

App 內「設定 → 實機驗收」可逐項標記並複製文字報告（不含照片），手機上的 AI 去背、人體辨識、試穿合成耗時會自動記錄。

## 驗證方式說明

| 代號 | 意思 |
|---|---|
| 📱 實機 | 在真實 iPhone 上確認過（附日期與環境） |
| 🤖 CI | GitHub Actions 上以 Playwright Chromium 模擬 iPhone 13 / Pixel 7，使用真實 AI 模型自動測試。**不是 Safari、不是真實手機硬體** |
| ⬜ 未驗證 | 尚無實機結果 |

## 已知限制（實機也無法改變）

- iPhone Safari 沒有 JSPI，AI 一律用 WASM CPU 執行（不影響功能，速度較 GPU 慢）
- iPhone Safari 不提供電量資訊，自動省電無效，需手動選「省電」
- iOS 可能清除長時間未開啟網站的資料：請定期匯出備份
- 試穿是圖像變形與合成，不是生成式 AI：不重建布料皺褶、光影與被遮住的部分
